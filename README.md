# ✂️ OMBRIX — Digital Inauguration & Concert Celebration

An interactive ceremonial inauguration and concert celebration website revealing **`OMBRIX`**.

---

## 🚀 Features

- **Interactive Ribbon Cutting**: Snip the royal crimson satin ribbon with golden shears.
- **Dual-Track Audio Experience**:
  - 🪔 **Ganpati Song**: Plays during the ceremonial cut, countdown, and cloth removal.
  - 🎵 **"Abhi Toh Party Shuru Hui Hai"**: Plays when the company name is revealed.
- **Dramatic 3... 2... 1... Countdown**: Sub-bass ticks and golden chimes.
- **Automatic Ceremonial Silk Cloth Unveil**: Royal velvet cloth with bullion gold fringe tassels slides down smoothly over 2.6 seconds.
- **Grand Concert Stage**:
  - Radiant golden **OMBRIX** logotype.
  - Illuminated glowing neon silhouettes (*Groove Solo*, *Gala Couple Dance*, *Festival Jump*).
  - Floating balloons, stadium confetti cannons, and interactive fireworks.
  - Real-time audio equalizer waveform.
- **Group Members Roster**: Clean display of all 15 cohort members with exam status notes.

---

## 🛠️ Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start dev server
npm run dev

# 3. Build for production
npm run build
```

Run locally at `http://localhost:5173/`.
